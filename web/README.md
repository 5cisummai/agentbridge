# agentbridge web

React (Vite) OAuth UI for the gateway. Auth screens follow the Afterlane login/signup layout with shadcn (radix-nova) + Tailwind.

```bash
pnpm install
pnpm build                 # → dist/
pnpm build --watch         # while developing against `pnpm --dir server dev`
pnpm exec shadcn add …     # add more UI primitives
```
